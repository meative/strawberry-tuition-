Strawberry Field ・ Operation Manual

月謝管理アプリ 操作説明書

事務員向け ／ 毎月の操作はこれだけ
このアプリは、月寒園・白石園・サッポロファクトリー園・幼稚舎・資生館保育園の月謝を一括管理するためのものです。画面上部の「現在の園」を切り替えると、その園の園児・料金が表示されます。毎月の作業は、本書の「3. 使い方の順序」だけを順番に行えば完了します。

1設定 と 園児台帳 について

この2つは、アプリ全体の「土台」です。ここが正しければ、他のタブは自動で正しく計算されます。

① 設定タブ ── 料金と振込先の大もと

設定

各園の料金体系（枠区分ごとの単価）と施設ごとの振込先口座を管理する場所です。料金は枠ごと・園ごとに編集できます。

ここで金額を変えると、月次計算・ルクミー出力・本部用集計などすべてに自動で反映されます。普段は触る必要はなく、料金改定や口座変更があったときだけ確認・修正します。

ポイント　日々の業務では設定タブはほとんど開きません。「最初に1回ちゃんと設定しておけば、あとは自動」という土台のタブだと考えてください。

② 園児台帳タブ ── 園児名簿の中心

園児台帳

在園している園児の名簿です。名前・所属園・クラス・枠区分・兄弟の有無・口座名義・納入方法（振込/引落）などを管理します。すべての計算は、この台帳の内容をもとに行われます。

クラスは生年月日から自動で決まります。「納入方法」欄では、その園児が 引落（既定）か 振込 かを選べます。振込の園児は色付きで一目で分かります。

園児台帳がすべての中心です。
園児台帳 → 月次計算（請求額の計算）→ ルクミー出力 → 本部用集計 → 再振替・再振込案内
注意　兄弟割引・納入方法・退園などの変更は、原則この園児台帳で行います。新しく入る園児だけは「新規入園」タブから入れます（次章で説明）。

2各タブの役割

上部に並ぶタブの意味です。連動 が付いたタブは、園児台帳などと自動で連動して数字が変わります。よく使うものから順に説明します。

入力するタブ（情報を足す）

新規入園 連動

途中入園を含め、新しく入る園児を登録するフォームです。入力して「確定」を押すと、園児台帳に自動で追加され、月次計算・ルクミー出力・本部集計にも反映されます。

「オプション」ボタンから制服・マットレス・おむつなどの初回費用も追加でき、初月合計と初回案内PDFに明細として載ります。

追加申込み 連動

制服の追加購入・行事費・返金など、月謝以外の臨時の増減を入力します。種別で「申込」「返金」を選び、金額と反映する月を入れると、その月の月次計算に反映されます（返金はマイナス）。

年間スケジュール

遠足・お泊まり会・運動会など、イレギュラーに徴収する項目を年間で登録します。状態を「確定」にすると、その月の月次計算に自動で加算されます。クラス単位・個人単位の指定もできます。

給食記録 連動

幼稚舎で、お弁当やパンを忘れた日の実費を記録します。日付と園児を選んでチェックすると、月集計が翌月の月次計算に自動反映されます。（幼稚舎・全施設表示のときだけ出るタブです）

確認・計算するタブ

月次計算 連動

その月の請求額が一覧で自動計算される、毎月の中心画面です。対象年・対象月を選ぶと、台帳・新規入園・追加申込み・年間スケジュール・給食記録の内容がすべて合算されて表示されます。

振込の園児は紫色の行で表示されます。各行の「再請求」チェックは、引落できなかった園児に印を付けるための欄です（後述の案内タブと連動）。

本部用集計

園別の内訳と全園合計を確認できる、本部報告用の集計画面です。「全施設」を選ぶと全園まとめて見られます。

出力するタブ（書類を作る）

ルクミー出力 連動

その月の請求対象を一覧表示します。ルクミーへは手入力のため、前月から金額が変わった園児・フラグのある園児（黄色の行）に 「手入力確認」チェックと担当者名を記録でき、転記ミスを防ぎます。

使う順番は「①内容を確認 → ②『全員にチェック』 → ③担当者を選んで『全員に設定』」。一人で担当する場合はこれで全員に同じ担当者が入ります。担当者はチェックした後でないと選べません。設定済みを外したいときは「担当を一括解除」または各行で個別に変更します。「変動・フラグのみ表示」の絞り込みと、確認済み件数の進捗バーも付いています。

チェック済みなのに担当者が未設定だと、他のタブへ移動できません（誰が未設定かエラーで表示）。チェックは月ごとに保存されます。

初回案内PDF出力

「新規入園」で登録した園児へ渡す、初回の振込案内状を表示します。発行日を変えると振込期限も自動で再計算されます。

再振替・再振込案内 連動

引落できなかった園児への督促状（月謝納入のお願い）を作るタブです。上部の「💳 振込の人」「🏦 引落の人」タブで、園児台帳の納入方法に応じて自動的に分かれて表示されます。

振込の人には振込先口座入りの案内、引落の人には再振替日の案内が出ます。「JPEG保存」で画像にして連絡帳に貼り付け、「印刷」で紙やPDFにできます。月謝＋事務手数料が請求額です（資生館は手数料550円、その他660円）。

スプレッドシート(xlsx)に出力

画面下のボタンから、全データをExcel形式で書き出せます。バックアップやGoogleドライブ保存に使います。

README

アプリ内に組み込まれた簡易説明です。困ったときの早見表として使えます。

3使い方の順序（毎月の操作）

毎月の作業はこの順番だけで完了します。最初に画面上部で「現在の園」「対象年」「対象月」を合わせてから始めてください。

  1. 入退園・変更を反映する
    新しく入る園児は 「新規入園」 から入力して「確定」。これで園児台帳に自動で追加されます。
    退園・兄弟割引・納入方法（振込/引落）の変更などは 「園児台帳」 で直接直します。
  2. 臨時の費用・記録を入れる
    行事費や制服の追加・返金は 「追加申込み」、遠足などの一斉徴収は 「年間スケジュール」（状態を「確定」に）、幼稚舎のお弁当忘れなどは 「給食記録」 に入力します。その月に必要な分だけでOKです。
  3. 月次計算で請求額を確認する
    「月次計算」 を開くと、ここまでの入力がすべて合算されて請求額が自動表示されます。金額に間違いがないか目で確認します。（ここで数字を直接打つ必要はありません。直したいときは元のタブを直します）
  4. ルクミーへ手入力し、確認チェックを付ける
    「ルクミー出力」 で当月の対象を確認します。ルクミーへは手入力なので、変わった園児（黄色）をルクミー側に入力したら、ここで 「全員にチェック」→ 担当者を選んで「全員に設定」。これが毎月27日の引落のもとになります。担当者が未設定だと他タブへ移れません。
  5. 引落結果を確認し、できなかった人に印を付ける
    銀行から届く「振込済み／資金不足」などの表を見て、引落できなかった園児を 「月次計算」 の 「再請求」チェック に入れます。
  6. 督促状を作って配る
    「再振替・再振込案内」 を開くと、チェックした園児が 「振込の人」「引落の人」 に自動で振り分けられて出ます。対象者を選び、「JPEG保存」で画像にして連絡帳に貼り付け、または「印刷」で配布します。

4アプリの開き方・データの注意

このアプリはインターネット上に公開されています。各園のiPadやパソコンのブラウザで、下のURLを開けば使えます。

アクセスURL

https://meative.github.io/strawberry-tuition-/

ブックマーク（お気に入り）に登録しておくと毎回入力せずに開けます。iPadなら「ホーム画面に追加」しておくとアプリのように使えます。

大切な注意：データの保存について
入力した内容（園児の追加・チェック・担当者など）は、そのiPad／パソコンのブラウザの中だけに保存されます。別の端末では共有されず、また同じ端末でもブラウザの履歴やデータを消すと失われます。大事な記録は、定期的に「スプレッドシート(xlsx)に出力」でバックアップを取ってください。複数人・複数端末で同じデータを共有したい場合は、別途その仕組みが必要になります（必要なら相談してください）。
覚えておくとラクなこと
・どのタブで入力しても、最後は必ず「月次計算」に集まります。だから金額の最終確認は月次計算を見ればOK。
・金額が違うと思ったら、月次計算で直すのではなく、もとのタブ（園児台帳・追加申込みなど）を直すと、全部が自動で直ります。
・園児が「振込」か「引落」かは 園児台帳の「納入方法」 で決まります。督促状のタブ分けもこれに従います。
・ルクミーは手入力。変わった人をルクミーに入力したら、必ず確認チェックと担当者を付けると転記漏れを防げます。
毎月の流れ（ひと目で）
新規入園・台帳更新 → 追加申込み・年間スケジュール・給食記録 → 月次計算で確認 → ルクミーへ手入力＋確認チェック → 引落結果を見て再請求チェック → 再振替・再振込案内を作って配布
